# Amanah Project

## Project Overview

Amanah is a Lost & Found reporting system designed to help users report, search, and manage lost or found items efficiently.

The application provides a simple and user-friendly interface that allows users to create reports, view item details, track report status, and manage their personal activity within the system.

The main goal of Amanah is to simplify the process of reporting lost and found items while improving communication between users.

---

## Main Features

- User authentication (Sign Up /  Log In)
- Create Lost or Found reports
- Upload item images
- View detailed report information
- Status tracking (Open / Resolved)
- Personal dashboard with statistics
- Profile management
- Ability to mark reports as resolved
- Ability to delete personal reports

## Creativity & Extra Features

### Status Management System

Users can update the status of their reports (Open / Resolved).  
This helps keep the system organized and ensures outdated reports are clearly marked.

### Dashboard Statistics

The system includes a dashboard that provides categorized statistics such as total reports, lost reports, found reports, and resolved reports.

### Ownership-Based Controls

Only the owner of a report has permission to modify or delete it, ensuring proper access control within the system.
