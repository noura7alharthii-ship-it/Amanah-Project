  	      Amanah – Lost & Found Reporting App
  	      Project Overview
  	      
  	      Amanah is a mobile application built using Flutter and Supabase that helps users report lost and found items in an organized and simple way.
  	      
  	      The main idea behind the project is to make it easier for people in universities, workplaces, or public spaces to report missing items and help others return them safely.
  	      
  	      The system allows users to create reports, upload images, add contact details, and manage the status of each report.
  	      Main Features
  	      
  	      User authentication using Supabase
  	      
  	      Create lost or found reports
  	      
  	      Upload item images
  	      
  	      Add contact information (Email or Phone)
  	      
  	      Search functionality
  	      
  	      Mark reports as Open or Resolved
  	      
  	      Delete report (owner only)
  	      
  	      Dashboard with report statistics
  	      
  	      How the App Works
  	      
  	      The user logs in.
  	      
  	      The user creates a new report (Lost or Found).
  	      
  	      The user fills in:
  	      
  	      Title
  	      
  	      Location
  	      
  	      Description
  	      
  	      Contact information
  	      
  	      Optional image
  	      
  	      Other users can browse reports and contact the owner.
  	      
  	      The report can be marked as resolved once the issue is handled.
